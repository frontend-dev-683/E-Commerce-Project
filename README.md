# E-Commerce Website 🛒

## Description

This is a responsive E-Commerce web application built using React.js and Tailwind CSS.

Users can browse products, view product details, filter products by category, and add or remove products from the shopping cart.

The application uses the Fake Store API to fetch product data and React Router DOM for navigation between pages.

## Features

- Responsive user interface
- Browse products
- View product details
- Filter products by category
- Add and remove products from the cart
- Cart management
- Navigation using React Router DOM
- Product data fetched from Fake Store API

## Technologies Used

- React.js
- JavaScript (ES6+)
- Tailwind CSS
- React Router DOM
- Fake Store API
- Vite
- Git & GitHub

## Prerequisites

Before running this project, make sure you have installed:

- Node.js
- npm

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/frontend-dev-683/E-Commerce-Project.git
   ```

2. Navigate to the project directory:

   cd E-Commerce-Project

3. Install dependencies:

   npm install

## Usage

Start the development server:

npm run dev

Open the local URL provided in your terminal to view the application.

## Build

To create a production build, run:

npm run build

## API

Product data is fetched from the [Fake Store API](https://fakestoreapi.com/).
